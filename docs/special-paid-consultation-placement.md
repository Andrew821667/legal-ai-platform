# Special Paid Consultation Placement Policy

Обновлено: 2026-03-12

Цель:
- закрепить, где специальные платные консультации можно показывать системно;
- не размывать бесплатный вход в платформу;
- иметь единый reference до UI/payments-правок в `web`, `lead-bot` и admin flows.

## 1. Базовое правило

По умолчанию:
- `обычная консультация` остается бесплатной;
- `special paid consultation` — отдельный дополнительный слой;
- пользователь не должен воспринимать весь консультационный вход как платный.

## 2. Где показывать можно

### Lead-bot
Разрешенные точки:
- экран `Цены`;
- экран `Помощь`;
- после обычного handoff как дополнительная опция;
- по явным триггерам срочности и углубленного формата:
  - `срочно`
  - `сегодня`
  - `нужно письменное заключение`
  - `разберите документы до созвона`

Допустимые формулировки:
- `Срочный экспертный формат`
- `Консультация с разбором документов`
- `Письменное заключение / expert memo`
- `Особый платный формат`

### Web
Разрешенные точки:
- отдельный блок `Специальные форматы консультации`;
- отдельная страница или отдельный сегмент FAQ;
- post-lead confirmation screen как мягкий upsell, но не как основной CTA.

### Admin / operator flows
Разрешенные точки:
- ручной перевод лида в special-format ветку;
- создание order после квалификации;
- отправка индивидуальной payment link только после явного согласования формата.

## 3. Где показывать нельзя

### Lead-bot
Не показывать как основной путь:
- в `/start`;
- в первом welcome-сообщении;
- в первом workspace-entry экране;
- в экране выбора профиля;
- в consent-экранах.

### Web
Не подменять special-format предложением:
- главную бесплатную lead form;
- первый hero CTA;
- бесплатные lead magnets;
- copy вида `начните бесплатно`.

## 4. Логика маршрута

Правильный маршрут:
- `бесплатный вход` -> `понимание задачи` -> `если нужен особый формат` -> `special paid consultation`.

Неправильный маршрут:
- `первый экран` -> `платите за консультацию`.

## 5. Какие продукты считаем допустимыми

Для первого платежного контура допустимы:
- `urgent_consultation`
- `document_review_consultation`
- `written_memo`

Что не продвигаем через этот слой:
- monthly SaaS subscription;
- общий paywall на вход в `Contract_AI_System`;
- оплату обычной 30-минутной консультации.

## 6. Copy guardrails

В интерфейсе всегда должно быть ясно:
- бесплатная консультация остается бесплатной;
- special-format — это отдельный экспертный режим;
- цена и способ оплаты могут идти отдельно от обычного lead flow.

Запрещенные смысловые смещения:
- `консультация = платная по умолчанию`;
- `без оплаты нельзя обсудить задачу`;
- `special-format` как замена бесплатному маршруту.

## 7. Что делать следующим кодом

- добавить отдельный UI entry для special-format в `lead-bot` экран `Цены`;
- добавить отдельный secondary block в `web` без изменения главного hero CTA;
- привязать новый `core-api` payment/order contour именно к этим точкам входа.
