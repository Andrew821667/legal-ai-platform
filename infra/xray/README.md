# Балансировщик Xray для Telegram-контура

Держит пул VPN-узлов, через который контейнеры ходят в Telegram. Контейнеры
обращаются к нему по `TELEGRAM_API_PROXY_URL=http://192.168.64.1:10811`.

Файл здесь — эталонная копия того, что установлено на production-хосте в
`/usr/local/sbin/xray-balancer-sync.py`. Скрипт системный и запускается от root
через `launchd`, поэтому в дереве приложения он не лежит: копия нужна, чтобы
изменения версионировались и не терялись при переустановке хоста.

## Что делает

Собирает пул узлов и перезагружает балансировщик только при изменениях.
Источник — подписка VPN: сначала пробуется кэш Happ, затем прямая загрузка по
HTTPS. Второй путь основной, потому что Happ по требованию эксплуатации
выключен и его кэш не пополняется.

## Ограничение по устройствам

Подписка разрешает ограниченное число одновременных устройств (на 02.09.2026 —
пять). Observatory держит соединение с каждым узлом пула, поэтому большой пул
исчерпывает лимит сам по себе: провайдер начинает отдавать вместо узлов
служебные заглушки с текстом об ограничении, и канал деградирует целиком.

Поэтому пул ограничен `XRAY_BALANCER_MAX_POOL` (по умолчанию 3), а проверки
узлов выполняются последовательно раз в 120 секунд. Уменьшать интервал или
увеличивать пул без запаса по лимиту устройств нельзя.

Заглушки провайдера отфильтровываются по ключевым словам в названиях узлов —
без этого они попадают в пул как неработающие прокси.

## Установка

```bash
sudo install -m 755 -o root -g wheel infra/xray/xray-balancer-sync.py \
  /usr/local/sbin/xray-balancer-sync.py
```

Адрес подписки лежит отдельно, в `/usr/local/etc/xray-balancer-sub-url`
с правами `600`. В репозиторий он не попадает.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `XRAY_BALANCER_MAX_POOL` | Размер пула, по умолчанию 3 |
| `XRAY_BALANCER_ALLOW_LTE` | Разрешить LTE-узлы. Временная мера: они медленные и лимитированные |

Задания: `ru.legalai.xray-balancer` (сам балансировщик) и
`ru.legalai.xray-balancer-sync` (обновление пула каждые 30 минут) в
`/Library/LaunchDaemons/`.

## Диагностика

```bash
# состояние пула и параметры проверок
python3 -c "import json;d=json.load(open('/Users/andrej/xray-balancer/config.json'));print(len([o for o in d['outbounds'] if o.get('tag','').startswith('proxy-')]),d.get('observatory'))"

# серия запросов через балансировщик
for i in $(seq 1 10); do curl -s -o /dev/null -w "%{http_code} %{time_total}s\n" \
  --max-time 15 --proxy http://192.168.64.1:10811 https://api.telegram.org/; done

# лог обновления пула
tail -20 /Users/andrej/Library/Logs/xray-balancer-sync.log
```

Признак упора в лимит устройств: в логе синхронизации появляются строки
`subscription returned N service placeholders`, а запросы через балансировщик
начинают возвращать `000`.
