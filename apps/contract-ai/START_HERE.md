# Contract AI: с чего начать сейчас

Этот файл больше не описывает “уже работающий в фоне demo-сервер” и не должен использоваться как источник для публичных адресов, старых IP или legacy-процедур.

## Актуальная точка входа

Используйте:

1. `README.md` — обзор подсистемы и назначение модулей.
2. `QUICKSTART_LOCAL.md` — безопасный локальный запуск.
3. `DOCKER_SETUP.md` — контейнерный запуск, если нужен отдельный стенд.
4. `TESTING_GUIDE.md` — ручные проверки.

## Что важно помнить

- `contract-ai` сейчас позиционируется как pilot/workspace контур, а не как публичный self-serve SaaS по умолчанию.
- Публичный billing и demo-сценарии выключены по умолчанию и должны включаться только осознанно.
- Любые старые инструкции с внешними IP, “уже запущенным Streamlit” или предсказуемыми demo-учетками считаются устаревшими.

## Базовый локальный маршрут

1. Подготовить `.env` из `.env.example`.
2. Инициализировать БД через `python scripts/init_db.py`.
3. Запустить UI и API локально.
4. Войти под локально созданным admin-пользователем.
5. Проверить анализ документа и базовый workflow.

## Отдельно про demo-режим

`start_demo.py` оставлен только как изолированный аварийный режим для локальной демонстрации и требует явного `CONTRACT_AI_ALLOW_INSECURE_DEMO=1`. Это не штатный путь запуска.
